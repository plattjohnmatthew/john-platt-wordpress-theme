# Public distribution: defaults and personal information

The author requested that **John Platt remain the theme name/author credit**. The GitHub owner is consequently visible too. This is not an anonymous publication. Internal `john_platt`/`john-platt` identifiers retain that attribution and compatibility; they are not contact details or a connection to the original site's database.

The installable public theme contains:

- Lorem Ipsum default homepage headings, descriptions and quick-link prose.
- A Lorem Ipsum Writing archive introduction when no introduction has been entered.
- A header/copyright identity derived from the installing site's Site Title, not a hard-coded personal name.
- Empty contact email, LinkedIn and CTA destination defaults. The new owner enters their own values in WordPress.
- Functional labels such as Home, Writing, Projects, Contact, Pause, Mute and Get in Touch. These stay meaningful for navigation/accessibility rather than being replaced with Lorem Ipsum.
- The theme's GPL licence, authorship notice and owner documentation.

It does **not** contain the original owner's personal email, biography, brand-focused default prose, portrait, client logos, case-study videos/images, articles, application selections, database, uploads, menu configuration, analytics measurement ID, credentials, private development notes, computer paths or private Git history. The unhelpful placeholder screenshot is omitted rather than exposing original-site images.

No live-site settings or content were anonymised or overwritten: this is a separate public edition. Installing a theme does not erase already-saved values on an existing site. If adapting a site that already has personal data, review its Pages, Posts, Projects, Portfolios, menus, Media Library, ACF fields, Site Title, sharing metadata, plugin/analytics settings and backups separately. The theme cannot sanitise an existing database merely by being installed.

Use your own images, copy and licensed media. Do not assume published theme source gives permission to copy the original website's content. Never upload database dumps, credentials or private application material when sharing an adaptation of the theme.
