# Contributing

Open an issue with reproducible steps before proposing a large architectural change. Small fixes and clearer owner documentation are welcome. Keep accessibility/static fallbacks, native WordPress editing and the absence of a frontend framework intact.

Fork the repository, use a branch, include meaningful checks and explain the user-visible change in your pull request. Contributions must be compatible with GPL-2.0-or-later. Do not include customer data, uploaded media, database dumps, credentials or unlisted application URLs.

See docs/DEVELOPMENT.md for architecture, tests and release building. GitHub Issues are public: report a suspected security issue without exploit details or credentials first, so a private reporting channel can be arranged. No guaranteed response time is offered.
